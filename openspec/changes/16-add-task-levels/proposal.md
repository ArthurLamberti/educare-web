# Proposal: Task levels (pages)

## Why
Choose, show and filter by the task level added by educare-api change 16.

## What Changes
- Task form: "Nível" select (optional) filled from `GET /api/levels`, never hard-coded.
- Task library and assignment lists: level badge (code) and a "Nível" filter.

## Impact
- Depends on educare-api change 16-add-task-levels.
