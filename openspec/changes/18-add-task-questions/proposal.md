# Proposal: Question blocks in tasks (pages)

## Why
Write, answer and grade tasks made of questions (educare-api change 18).

## What Changes
- Task form: "Perguntas" block to add, edit, reorder and remove open questions; instructions become optional when there are questions.
- Answer page: one numbered field per question below the instructions, kept in drafts too.
- Assignment and grading pages: each question with the student's answer under it.

## Impact
- Depends on educare-api change 18-add-task-questions.
