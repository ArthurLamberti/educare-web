# Proposal: Task categories (pages)

## Why
Manage, choose, show and filter by the teacher's task categories (educare-api change 17).

## What Changes
- `/tasks/categories`: list with task counts, create, rename and delete (deleting tells how many tasks lose the category).
- Task form: "Categoria" select with the teacher's categories and "Nova categoria" inline.
- Task library and assignment lists: category badge and a "Categoria" filter.

## Impact
- Depends on educare-api change 17-add-task-categories.
